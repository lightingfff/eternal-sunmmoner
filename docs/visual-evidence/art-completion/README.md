## Measurements and limits

`reports/cold-init-host.json` is a fresh isolated test: Lobby508.38ms,
Tower98.86ms, gates32.49ms, warm preload.0056ms. Listed retained bitmap pixels
total27,570,400bytes. `frame-probe-host.json` records native host raster CPU
timing, including test bitmap creation; it is not a device frame-time benchmark.
Neither report includes total process memory, GPU work, thermal or input latency.
The synchronous initial asset load remains a performance concern needing phone
profiling, despite warm caches and no per-frame decoding.

`adb devices -l` returned no devices. Physical install/update, frame pacing,
FPS/GPU/heat/battery, Android OOM injection and human gameplay/creative acceptance
are **NOT TESTED**. Existing local and CI debug certificates differ; no signing
configuration was changed. Use the actual CI artifact for device acceptance;
the locally signed APK does not prove update compatibility with a CI installation.
Repeated grass patterns, baked sprite light under reflection and fewer authored
directions than a full 3D model remain explicit visual limitations.
